# Python Day 137 - Count Digits in a String

## Description
This Python program counts how many digit characters are present in a string entered by the user.

## Example
**Input:** `hello123world45`

**Output:** `Total digits: 5`

## Concepts Used
- Strings
- For Loop
- If Statement
- isdigit()
- Counter Variable

## How to Run
Run `count_digits_string.py` using Python and enter a string.
